Dérouler le skill `carnet-de-reprise` :

- avec un code en argument → `carnet_de_formation` mode `decoder`,
  confirmer ce qui est relu, puis enchaîner sur `lecon_suivante` ;
- sans argument → mode `encoder` avec les `slugsVus` de la séance en cours
  (les lister pour validation avant d'encoder), puis remettre le code à
  garder.
